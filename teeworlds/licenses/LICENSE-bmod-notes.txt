Settings
--------

sv_bot_slots          Number of slots to reserve for bots (default 2)
sv_bot_skin           Bot skin (default "default")
sv_bot_allow_hook     Bots are allowed to hook (default 1)
sv_bot_allow_move     Bots are allowed to move (default 1)
sv_bot_allow_fire     Bots are allowed to fire (default 1)
sv_bot_draw_target    Show bot target, debug only (default 0)
sv_botengine_draw_graph  Draw pathfinding graph, debug only (default 0)

The AI
------

Each tick: picks a target among pickups/enemies (or a random spot if
none are relevant), paths to it via a pathfinding graph built from a
triangulation of the map's empty space on load, predicts projectile
trajectories to decide whether firing would land a hit, and moves
(jumping over gaps, using the hook when it would help). It does not
retreat and does not coordinate with other bots.
